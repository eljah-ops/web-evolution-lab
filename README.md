# Web Evolution Lab 2026

Projet web expérimental qui met en avant trois APIs natives du navigateur :

- HTML Popover
- CSS Anchor Positioning
- View Transition API

## Présentation

Cette page interactive montre comment le navigateur peut gérer certaines interfaces modernes sans dépendre de bibliothèques externes. Elle propose une démonstration visuelle et pédagogique de trois fonctionnalités natives du web.

## Fonctionnalités

- Bouton pour ouvrir un popover HTML natif
- Menu ancré automatiquement via CSS Anchor Positioning
- Transition fluide entre deux états avec View Transition API
- Basculer entre mode clair et mode sombre

## Structure du projet

- index.html : structure HTML de la page
- styles.css : styles et thème responsive
- script.js : interactions JavaScript et animations

## Lancer le projet

Ouvrez simplement le fichier index.html dans votre navigateur
